# Suryapura Gram Panchayat Portal

This is a web portal designed for the Suryapura Gram Panchayat. It provides a simple way for village citizens to access government schemes, apply for certificates, and register grievances online.

## Live Demo
[View Live Demo Here](https://satyajangir.github.io/channel009_task_demo/)

## Features
- Government UI theme with a top bar and the National Emblem.
- Accessibility tools including font-size resizers and a high contrast mode.
- Language toggle between English and Hindi.
- Mockups for e-Panchayat services like certificates and grievances.
- Widgets for local Mandi prices and weather forecasts.
- Mobile-friendly design that works well on all screen sizes.

## Technologies Used
- React.js
- Vite
- Lucide React
- Custom CSS

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/satyajangir/channel009_task_demo.git
   ```

2. Navigate to the project folder:
   ```bash
   cd channel009_task_demo/suryapura-portal
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
